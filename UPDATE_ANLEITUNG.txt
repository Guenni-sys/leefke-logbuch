LEEFKE Bordtagebuch – Update auf Version 5.1

NEU
- Handy, Tablet und Laptop sind gleichberechtigt.
- Änderungen eines Geräts werden automatisch in die Cloud übertragen.
- Andere geöffnete Geräte prüfen alle 20 Sekunden auf neue Daten.
- Beim Öffnen, Zurückkehren zur App oder Wiederherstellen der Internetverbindung wird sofort synchronisiert.
- Gleichzeitige Änderungen gehen nicht mehr verloren; die zeitlich neuere Fassung gewinnt.

WICHTIG
Eine auf iPad oder Handy vollständig geschlossene App kann ihren lokalen Speicher nicht im Hintergrund aktualisieren. Die Daten liegen aber bereits in der Cloud und werden beim nächsten Öffnen sofort geladen.

INSTALLATION
1. In der bestehenden App unter „Sicherung“ eine Sicherung exportieren.
2. Diese ZIP-Datei unter Windows vollständig entpacken.
3. GitHub öffnen: https://github.com/Guenni-sys/leefke-logbuch
4. Add file → Upload files.
5. Alle Dateien aus diesem Ordner hochladen – nicht die ZIP-Datei.
6. Commit changes anklicken.
7. Zwei bis drei Minuten warten.
8. Öffnen: https://guenni-sys.github.io/leefke-logbuch/index.html?v=5.1
9. Unter Windows Strg + F5 drücken. Auf iPad/Handy die App vollständig schließen und neu öffnen.

Es sind keine neuen SQL-Befehle in Supabase nötig. Das bestehende Konto und die vorhandenen Daten bleiben erhalten.
